# New Shades Eluru — Salon Booking App

Premium salon appointment booking web app for **New Shades Eluru**.

**Live:** [www.newshadeseluru.in](https://www.newshadeseluru.in)

## Stack
- Frontend: HTML, Bootstrap 5, Vanilla JS
- Backend: Firebase Firestore
- Auth: Firebase Authentication
- Hosting: GitHub Pages

## Structure
```
docs/               ← GitHub Pages root
├── index.html      ← Home
├── login.html
├── about.html
├── services.html
├── gallery.html
├── contact.html
├── admin/          ← Admin panel
├── customer/       ← Customer portal
├── employee/       ← Employee portal
├── js/
│   ├── firebase.js
│   └── main.js
├── images/
└── style.css
firestore.rules     ← Firestore security rules
firebase.json
```
